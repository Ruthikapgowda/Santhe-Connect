# Santhe-Connect Submission Checklist

## Required Items

- Public GitHub repository URL: `https://github.com/Ruthikapgowda/Santhe-Connect`
- Complete Android source code: included under `app/src/`
- README.md: includes project explanation, setup steps, features, tech stack, and Firebase schema
- Dependency/config files: Gradle files, Gradle wrapper, `gradle.properties.example`, and `app/google-services.example.json`
- Screenshots/demo link: add screenshots under `screenshots/` or add an APK release link in README when available
- Meaningful commits: project contains multiple commits showing setup and app progress

## Before Final Submission

1. Push latest changes to GitHub.
2. Confirm `gradle.properties`, `local.properties`, `app/google-services.json`, `app/build/`, and APK files are not committed.
3. Add screenshots or paste the APK release link in README if available.
4. Open the GitHub repository in an incognito browser and verify all files are visible.
